O seu Excel, ligado à app

Um ficheiro no Ambiente de Trabalho com o controlo financeiro, Obras, Faturas, Materiais e Movimentos. A coluna Estado da Obra muda para Concluída quando concluir a obra na app.

Precisa de Microsoft Excel 2016 ou mais recente no Windows, com Power Query (recomendado: Microsoft 365). Com internet e o ficheiro aberto, as tabelas consultam a app a cada 5 minutos e ao abrir. Com o Excel fechado não há atualização. As fotografias e os PDFs ficam na app; o Excel mostra os dados e se existe anexo.

1. Preparar o acesso

Entre na app neste navegador primeiro. Em seguida, crie a palavra-passe exclusiva do Excel. Este acesso permite consultar os dados, sem os alterar.

Utilizador: enat

Guarde-a no seu gestor de palavras-passe. Só aparece nesta página logo após a criação. Não use o código de recuperação da app.

2. Criar o ficheiro no computador

Para obter o novo desenho ENAT: descarregue novamente o assistente e crie um novo ficheiro. Pode usar o acesso do Excel que já guardou, sem criar outra palavra-passe. O ficheiro antigo fica preservado. «Atualizar Tudo» atualiza os dados, mas não altera o desenho de ficheiros criados anteriormente.

  1. No computador Windows onde tem Excel, carregue em Descarregar assistente.
  2. Abra a pasta Transferências e dê dois cliques no ficheiro Criar-Excel-ENAT.vbs. Este assistente abre o seu Excel e cria ENAT-Financas.xlsx no Ambiente de Trabalho. Não substitui ficheiros anteriores.
  3. Na janela de ligação do Excel, escolha Básico. Escreva enat no utilizador e cole a palavra-passe do passo 1. Escolha Ligar. Se aparecer um nível de privacidade, escolha Privado para esta origem.
  4. Se o Excel mostrar um aviso de ligações externas, permita a ligação neste ficheiro ENAT. Aguarde que as tabelas recebam os dados e guarde o ficheiro.

3. Usar no dia a dia

Registe as obras, faturas, despesas e recebimentos na app normalmente. Depois abra o ficheiro do Ambiente de Trabalho. Os dados chegam ao abrir e de cinco em cinco minutos. Para os receber já, escolha no Excel Dados → Atualizar Tudo.

O aspeto segue o modelo das imagens: indicadores no topo, cabeçalho azul, tabela com filtros e folhas de detalhe. Os números são calculados a partir dos dados guardados na app. Não escreva por cima destas tabelas: a próxima atualização substitui as alterações. Guarde o Excel depois de atualizar para conservar os últimos dados disponíveis sem internet.

4. Usar noutro computador

Copie o ENAT-Financas.xlsx para esse computador, por exemplo através de uma pen USB ou OneDrive. Abra-o no Excel para Windows e introduza novamente o utilizador enat e a mesma palavra-passe quando for pedido. As credenciais são configuradas em cada computador. Também pode executar o assistente nesse computador.

Se não aparecerem dados

  • Confirme que tem internet e que a app mostra os dados sincronizados. As alterações ainda guardadas só no telemóvel não chegam ao Excel.
  • No Excel, escolha Dados → Atualizar Tudo. Consulte Dados → Consultas e Ligações para ver um eventual erro.
  • Se escolheu «Anónimo» ou a palavra-passe mudou: Dados → Obter Dados → Definições da origem de dados, selecione a ligação ENAT e escolha Editar permissões (ou Limpar permissões). Volte a atualizar e escolha «Básico».
  • Para confirmar o intervalo: Dados → Consultas e Ligações → Ligações → Propriedades. Verifique «Atualizar a cada 5 minutos» e «Atualizar dados ao abrir o ficheiro». A localização destas opções varia com a versão do Excel.
  • Se o Windows impedir o assistente, não desligue a proteção do computador. Peça ajuda a quem gere o computador. O assistente usa a automação do Excel e o Windows Script Host; algumas empresas desativam esta função. O Excel Online e os leitores de folhas de cálculo não executam este assistente.

Desligar o Excel

Se perder um computador, pode revogar o acesso abaixo. As próximas consultas deixam de funcionar, mas os dados já guardados nos ficheiros continuam lá. Criar outro acesso também invalida a palavra-passe anterior em todos os computadores.
